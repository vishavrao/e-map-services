# EMAP Services

Company portfolio website for E Map Services, Gurgaon, working since 2021.

## Run locally
Open index.html, or run `python -m http.server 8080` and visit http://localhost:8080.

## Publish
GitHub Pages: deploy main branch, root folder. No build step or dependencies required.

## Features
Responsive design, 19 supplied project photos, category filters, accessible photo viewer with keyboard navigation, services, vision, execution process, 12 company strengths, client grid and office map link.

## Assets and content
Company branding and all portfolio photographs supplied by the owner. Client names are displayed as text because official client logo files were not supplied. Business phone and email are linked. Instagram was not provided and is omitted. The map link searches the supplied address. Fonts load from Google Fonts with system fallbacks.
